# its203-attendance-registry
ITS 203 individual assignment
## Description
A Windows Forms desktop app (C#) that helps a lecturer or class coordinator
manage student attendance instead of using paper registers or spreadsheets.
Currently the app can add students (ID and name), save them to students.csv,
and display them in a list. Classes for attendance records and file handling
(AttendanceRecord, DataManager) are also built.

## How to Run
1. Clone or download this repository.
2. Open AttendanceRegistry/AttendanceRegistry.slnx in Visual Studio.
3. Press F5 to build and run.

## Setup
- Visual Studio 2022 with the ".NET desktop development" workload installed.
- The data files (students.csv, attendance.csv) are created automatically
  on first run if they don't exist.
